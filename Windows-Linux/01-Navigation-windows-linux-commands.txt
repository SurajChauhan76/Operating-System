All about ls on powershell: 
Mode column:  acts as a visual shorthand representing a file or directory’s system properties. Each character position in the string corresponds to a specific attribute. If an attribute is not set, it is represented by a dash (-).

File Attribute Modes (The Get-ChildItem column):
The attributes always appear in a specific, fixed order:
1. d (Directory): The item is a folder, not a file.
2. a (Archive): The file is ready for archiving or backup. Windows sets this automatically when a file is created or modified.
3. r (Read-only): The file is write-protected and cannot be easily altered or deleted.
4. h (Hidden): The file is hidden from normal directory listings.
5. s (System): The item is a critical operating system file.
6. l (Link/Reparse Point): The item is a symbolic link, hard link, or junction point.

Example: If you see a mode of "dar--", it tells you that the item is a Directory, has its Archive bit set, is Read-only, and is neither hidden nor a system file.

21. Delete / Remove files and folders:

PowerShell rm (alias of Remove-Item)
------------------------------------
Command              | Purpose                                      | Example
rm                   | Removes a file or empty folder               | rm "C:\Temp\file.txt"
rm -Force            | Removes hidden or read-only files            | rm "C:\Temp\secret.txt" -Force
rm -Recurse          | Removes folder and all contents              | rm "C:\Temp\OldLogs" -Recurse
rm -Force -Recurse   | Removes folder + hidden/read-only files inside | rm "C:\Temp\Backup" -Force -Recurse

* rm folder(with inside contents): Throws warning and asks for confirmation to delete.
* If you directly want to remove all contents with folder then use rm -Recurse.
* Removing hidden or read-only files/folders throws error showing no sufficient rights for this operation, use 'rm filename -Force' to remove.

Linux rm
--------
Command              | Purpose                                      | Example
rm file.txt          | Removes a file                               
rm -f file.txt       | Force remove (ignore nonexistent files, no prompt) | rm -f secret.txt
rm -r folder/        | Removes folder and all contents (recursive)  | rm -r old_logs/
rm -rf folder/       | Force + recursive (delete everything inside, no prompt) | rm -rf backup/

Notes:
- In PowerShell, rm is an alias for Remove-Item.
- In Linux, rm is a native command.
- Be careful with -Force (PowerShell) and -rf (Linux) — they delete without asking, which can cause irreversible data loss.

25. Searching within Files:

A. Select-String / sls: used to search the specified string within the file. It returns the line number and the line content with the searched string.

Format: Select-String "string-to-search" file_path

e.g. PS C:\Users\suraj> Select-String "nice" '.\Desktop\OS Command Practice Folder\1.txt'
     Desktop\OS Command Practice Folder\1.txt:1:hello world you are nice

e.g. PS C:\Users\suraj> sls "nice" '.\Desktop\OS Command Practice Folder\1.txt'
     Desktop\OS Command Practice Folder\1.txt:1:hello world you are nice

Input-Output:

28. Echo: Write text on Screen, File
Echo is alias for Write-Output.

A. echo: Alia for Write-Output: used to write the input text to be displayed on the PowerShell command screen.

e.g. PS C:\Users\suraj\Desktop> echo text
     text

B. echo "text" > filename: Print or override the input text to a file. If file does not exists then new file is created.

e.g. PS C:\Users\suraj\Desktop> echo "my help desk to the computer world. Hi I am suraj chauhan." > dog.txt
     PS C:\Users\suraj\Desktop> cat dog.txt			# cat used to get the content of dog.txt on PowerShell screen.
     my help desk to the computer world. Hi I am suraj chauhan.

C. Append text: echo "text" >> filename

e.g. PS C:\Users\suraj\Desktop> echo "I am from Rkl" >> dog.txt
     PS C:\Users\suraj\Desktop> cat dog.txt
     my help desk to the computer world. Hi I am suraj chauhan.
     I am from Rkl

Note: 1. ">": redirection for override
      2. ">>": redirection for append

31. A. "|": Bit operator: used to combine the commands together. It is used to send the output of one command to the input of another command (Pipeline).

A. Fetch content from file and Select string:

e.g. PS C:\Users\suraj\Desktop> cat dog.txt | Select-String st

B. Fetch content, select specific string and write to another file.

e.g. PS C:\Users\suraj\Desktop> cat dog.txt | Select-String ee > words.txt
     PS C:\Users\suraj\Desktop> cat words.txt
     street
     tree

32. "2>":  Diverting/Redirecting output errors from command screen to another file while deleting the hidden or read only file.
e.g. PS C:\Users\suraj\Desktop> rm secure_file.txt
This throws error on the screen right away.

e.g. PS C:\Users\suraj\Desktop> rm secure_file.txt 2> errors.txt
     PS C:\Users\suraj\Desktop> cat errors.txt
The output errors will be stored in errors.txt and it will display on cat on screen.

Difference between 1> & 2>:
1>: stdout - the output
2>: stderr - the error

# Redirecting error message to $null (to nothing or nowhere) - to filter the output from error message.

e.g. PS C:\Users\suraj\Desktop> rm words.txt 2> $null
     No error message stored as we don't care about the error here.

# Get-help about_redirection


Linux:
Input/Output Stream: stdin, stdout, stderr

* suraj@SurajVM:~$ echo woof > dog.txt  : override redirection dog.txt with woof.

* suraj@SurajVM:~$ echo woof >> dog.txt : append redirection

"<": used to get the input from a file rather than keyboard input.

* suraj@SurajVM:~$ cat < file_input.txt
Output: Some file input!

* suraj@SurajVM:~$ ls /dir/fake_dir 2> error_output.txt
  suraj@SurajVM:~$ cat error_output.txt
Output: ls: cannot access '/dir/fake_dir': No such file or directory.

# Redirecting error message to "/dev/null"
* suraj@SurajVM:~$ less /var/log/syslog 2> /dev/null
Now the output is filtered from the error message.

# "|": pipe redirector - used to send input of one command to the output of another command (Pipeline).
* suraj@SurajVM:~$ ls -la /etc | grep Bluetooth
Output: drwxr-xr-x 2 root root 4096 Oct 5 13:38 Bluetooth
