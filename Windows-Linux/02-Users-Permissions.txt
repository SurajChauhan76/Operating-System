Users and Permissions:

A single computer is used by multiple account holders. These users are isolated from each other. No users can see or have the access to the other users files and directories.

Types of Users:
1. Standard users
2. Administrators

Standard Users: One who is given access to a machine but has restricted access to do things like install software or change certain settings.

Administrator(Admin): A user that have complete control over a machine. (All access & rights). 

Admin can view anyone's account, change or remove anyone on the computer, and can view every single file.

Admin maintains the software installs and restrictions for the different users on public machine/computers.

For a Personal Computer:
Admin: All access and rights
Parents: Can't install software
Children: Can't install software. Child safety restrictions.

Create new user and group:
** Run the PowerShell as Administrator **

1. Create a New User: 
New-LocalUser -Name "TestUser" -Password (Read-Host -AsSecureString "Enter Password") -FullName "Test User" -Description "Practice account"

Check: Get-LocalUser TestUser

2. Update/Edit User Details:

Local User (Windows machine):
Set-LocalUser -Name "testuser3" -Description "Practice Account 3"

Domain User (Active Directory):
If you’re in a domain environment, you’ll use Set-ADUser (requires RSAT or AD module).

e.g. # Update display name
Set-ADUser -Identity "suraj.chauhan" -DisplayName "Suraj Chauhan"

# Update email address
Set-ADUser -Identity "suraj.chauhan" -EmailAddress "suraj@example.com"

# Update multiple properties at once
Set-ADUser -Identity "suraj.chauhan" -GivenName "Suraj" -Surname "Chauhan" -Office "Gurugram"


3. Create a New Group: 
New-LocalGroup -Name "TestGroup" -Description "Practice Group"

Check: Get-LocalGroup TestGroup
-------------------------------------------------------------------------------------

3. Add Member to Group: 
Add-LocalGroupMember -Group "TestGroup" -Member "TestUser"

Check: Get-LocalGroupMember -Group "TestGroup"

4. Add multiple Members at a time: Add-LocalGroupMember -Group "TestGroup" -Member "User1", "User2"   # list of users passed in the form of array like preceding one.

Check: Get-LocalGroupMember -Group "TestGroup"

5. Looping for Many Users - If you have a longer list, you can store them in a variable and loop:

$users = @("TestUser C","TestUser D","TestUser E")

foreach ($u in $users) {
    Add-LocalGroupMember -Group "TestGroup 2" -Member $u
}
-------------------------------------------------------------------------------------------------

6. Remove/Delete Member out of the Group:  Remove-LocalGroupMember -Group "TestGroup" -Member "TestUser"

Check: Get-LocalGroupMember -Group "TestGroup"

A. Delete user: Remove-LocalUser -Name "TestUser"

B. Delete group: Remove-LocalGroup -Name "TestGroup"

10. Windows File Permission:
In Windows, files and directory permissions are assigned using Access Control Lists or ACLs. Specifically, we're gonna work with Discretionary Access Control Lists or DACLs.

Windows files and folders can also have System Access Control Lists or SACLs assigned to them.

A. Read: Lets you see that a file exists, and allows you to read its contents. It also lets you read the files and directories in a directory.

B. Read and Execute: Lets you read files, and if the file is an executable, you can run the file.
Read and Execute includes Read, so if you select Read & Execute, Read will be automatically selected.

Linux Password:
When you set a password it's securely scrambled, then stored in a special privileged file called /etc/shadow.

1. passwd username: To change the password


2. sudo passwd -e username: To force the standard user to change the password. This will immediately expire user's password and make them set new password the next time they login.

File Permissions in Linux: 3 types:
1. Read: Allows someone to read the contents of a file or folder.
2. Write: Allows someone to write information to a file or folder.
3. Execute: Allows someone to execute a program.

Command: ls -l ~/my_file
Output: -rwxrw-r-- 1 cindy cool_group 0 Oct 9 17:48 /home/cindy/my_file
Explanation: 1st trio (rwx) - read, write, execute permission given to user cindy.
2nd trio (rw-) - read, write permission given to group cool_group but no execute permission.
3rd trio (r--) - only read permission given to others.
